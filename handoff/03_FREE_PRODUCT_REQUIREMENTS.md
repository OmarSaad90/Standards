# Free Product Requirements

## The site is public and no-login

There is no authentication requirement.

## Free shows

- standard code
- public title/label
- subject
- grade(s)
- current/historical status
- domain/framework information
- source link
- source/version context
- Aedifica View
- public framework lineage
- generic evidence signals
- aggregate Supports / Reinforces / Next counts

## Free must NOT show

- exact relationship endpoints
- commercial relationship IDs
- per-edge rationale
- per-edge provenance
- per-edge confidence
- per-edge audit status
- commercial access states
- Expanded records
- Disputed records
- Quarantine records
- internal audits
- reconciliation fields
- educator-validation ledger
- customer overlays
- private curriculum data

## Claim boundaries

Do not imply:
- NJDOE approval of Aedifica relationships
- official prerequisite status
- educator validation unless actually supported
- district validation unless actually supported
- research-backed relationship claims unless actually supported

Use clear framing such as:
- Aedifica View
- public learning-context signals
- aggregate Supports / Reinforces / Next

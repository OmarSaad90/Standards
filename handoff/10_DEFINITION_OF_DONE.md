# Definition of Done

The Free Standards Explorer is done when:

## Product
- public/no-login
- useful search/browse
- shareable standard pages
- source and Aedifica View clearly separated
- aggregate relationship counts visible
- no protected graph details

## Technical
- SSR/SSG canonical standard URLs
- mobile responsive
- accessible primary flow
- stable search/filter URLs
- real 404s
- public API contract enforced

## Security
- no protected relationship IDs
- no endpoints
- no Expanded/Disputed/Quarantine rows
- leakage scan passes
- no secrets in client bundle

## Quality
- automated tests pass
- browser tests pass
- accessibility checks pass at agreed level
- SEO checks pass
- staging acceptance passes
- production-origin acceptance passes

## Final developer deliverables

1. repository access
2. staging URL
3. production URL
4. release tag / commit SHA
5. build instructions
6. environment template
7. tests
8. QA report
9. leakage report
10. production-origin acceptance report
11. deployed data/build hashes
12. maintenance README

# 09 — Accessibility, SEO and Performance

Accessibility:
- semantic structure
- keyboard operation
- visible focus
- dialog focus management and Escape close
- return focus
- accessible control labels
- polite result-count announcements
- no color-only meaning
- reduced motion
- WCAG 2.1 AA target

SEO:
- server-render/static standard pages
- unique title/description
- canonical URLs
- crawlable standard text
- subject/grade pages
- sitemap
- correct robots behavior

Performance:
- the 3.9 MB single HTML is a reference, not the desired final bundle
- avoid shipping all data unnecessarily on first paint
- cache public data
- split server/static content from interactive client code
- minimize layout shift and third-party scripts

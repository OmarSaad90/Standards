# 00 — Start Here

Build a production-quality **Free Standards Explorer** from the supplied reference.

The reference controls:
- visual direction and information hierarchy;
- public standard content;
- current/non-current behavior;
- search/filter semantics;
- ELA official-text presentation;
- source links and public evidence;
- aggregate Supports/Reinforces/Next counts;
- the relationship **coming soon** state.

Recommended architecture: Next.js App Router + TypeScript, or equivalent server-rendered framework.

Do not deploy the single-file HTML as the final architecture. Keep it as an immutable developer reference and build a maintainable application around the supplied production-data contract.

# 12 — Change Control

Implementation refactors are allowed if public meaning and acceptance tests remain unchanged.

Owner review is required before changing:
- code/text/source URL
- current status
- grade/band
- Aedifica View
- evidence signals
- framework metadata
- relationship counts
- ELA official wording/components
- NJDOE source-evidence semantics
- public routes
- exposed fields
- relationship product behavior

Never overwrite the reference artifact. Create a successor and document the delta.

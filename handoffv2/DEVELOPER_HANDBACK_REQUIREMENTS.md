# Developer Handback Requirements

Before requesting owner approval, return one package containing:

- staging URL;
- repository identifier/URL;
- Git commit SHA used for staging;
- deployment/build ID;
- framework/runtime versions;
- completed QA checklist;
- browser test matrix;
- accessibility results;
- SEO/crawlability results;
- performance results;
- known deviations from the reference;
- screenshots of home, search, filtered results, standard detail, current ELA with components, historical ELA, Math PCS evidence, subject page, grade page, mobile view, and the relationship-coming-soon state;
- confirmation that no exact relationship endpoints, relationship IDs, topology, rationale, confidence, detailed/private provenance, Source Graph Preview data, paid graph data, or customer curriculum data are exposed;
- confirmation that all governed public counts and ELA invariants still match;
- post-deployment smoke-test results if production promotion is authorized.

Do not describe the implementation as formally locked, independently audited, NJDOE approved, educator approved, or fully WCAG certified unless those are separately completed and documented.
